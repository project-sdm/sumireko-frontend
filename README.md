# Sumireko Frontend

Frontend para [Sumireko](https://github.com/project-sdm/sumireko), un sistema de recuperación multimedia con soporte para texto, imágenes y audio.

## Uso

Debes crear un archivo `.env` con la siguiente variable:

```bash
NEXT_PUBLIC_API_URL=<url-del-backend>
```

Con esto, puedes instalar las dependencies y ejecutar el frontend con los siguientes comandos:

```bash
pnpm install
pnpm run dev
```
